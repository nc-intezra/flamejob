API keys

Keys authenticate API requests as you (same roles). Send them as Authorization: Bearer fj_…. The secret is shown once at creation — store it then.

Sitewide settings

Serve this dashboard over HTTPS on tcp/443 with your own certificate. The plain HTTP dashboard on its existing port keeps working — this only adds an encrypted listener. The private key is stored encrypted and never shown again.

Tip: if you serve the dashboard over HTTPS, the API should be reachable over HTTPS too ([server].tls_cert or a proxy) — a browser blocks an HTTPS page calling an HTTP API.

Directory (AD/LDAP)

Sign in with corporate AD/LDAP credentials; flamejob roles are derived from AD security-group membership (matched on the group's immutable objectSid). The service-account password is stored encrypted and never shown again. You can view and test; only a superadmin can save or enable.

⚠ Plaintext LDAP — insecure

Test the saved config without locking anyone out. A successful service bind arms Enable.

Group → role map (matched on objectSid). A user gets the union of the roles of every group they belong to.

Agent pools (a named set of agents). A job runs only on agents in pools its owner's groups are granted. (view only — needs Manage agents)

Group → pool grants (matched on objectSid). Grants a security group access to a pool's agents.

Fair-share weights & quotas (per directory group). Higher weight = larger share of contested GPU slots; floor = guaranteed slots; ceiling = burst cap; max jobs = submit backpressure. Groups without a row use defaults (weight 100, no limits).
